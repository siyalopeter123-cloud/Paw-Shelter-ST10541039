# Paw Shelter Durban Website

Paw Shelter Durban is a small animal rescue and adoption website designed to help connect abandoned dogs and cats with loving homes in KwaZulu-Natal, South Africa.

## Website Purpose

The website promotes the rescue shelter and raises awareness for:
- animal adoption
- pet rescue and rehabilitation
- volunteer support
- donations and community care
- clothing merchandise sales to help fund shelter needs

## Website Pages

### Home Page (`index.html`)
- Main landing page for the shelter
- Introduces the organization and available pets
- Shows the paw logo and main shelter banner

### About Page (`about.html`)
- Explains the shelter story and mission
- Includes the vision, values, and team background
- Uses the same branding banner and logo as the home page

### Services Page (`services.html`)
- Highlights what the shelter offers
- Describes rescue, adoption, care, and support services

### Enquiry Page (`enquiry.html`)
- Lets users contact the shelter
- Includes a CEO access verification form
- If the correct CEO details are entered, the CEO information is displayed
- If incorrect details are entered, the information is hidden and an error message appears

### Contact Page (`contact.html`)
- Includes contact details and communication information
- Displays shelter contact information and the business location

### Clothing Page (`clothing.html`)
- Shows shelter merchandise products
- Displays clothing items and prices to help fund the rescue work

## Styling

The website uses a custom stylesheet in `style.css` with:
- warm brown and orange color palette
- responsive layout for desktop and mobile devices
- card-based sections and product layouts
- consistent shelter branding throughout the site

## JavaScript Functionality

The site script in `script.js` includes:
- reveal animations for content sections
- form validation for standard forms
- CEO verification logic
- clearing of CEO details when incorrect information is entered

## Image Assets

The project includes images in the `images/` folder, including:
- shelter logo
- shelter cover/banner image
- dog and cat rescue photos
- product images for clothing merchandise

## How to Run

To view the website locally:
1. Open the project folder in a browser
2. Double-click `index.html`
3. Or use a local web server if preferred

## Project Notes

This is a front-end static website built with HTML, CSS, and JavaScript. It is designed for presentation, adoption information, and contact/enquiry communication.
